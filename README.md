This is the locked in hackpad, my first hardware design. It is a 3x3 macropad, with a rotary encoder for volume and a 0.91 in OLED. 

The 9 buttons perform these functions: power off, system sleep, system wake, rewidn media, pause/play media, fast forward media, copy, paste, and find.

The hackpad case is decorated with a big LOCK IN text to remind the user (me) to stop scrolling and lock in. 

The non-plastic elements in the .step file were taken from GrabCad from these creators:
DSA keycap: zim cad
Cherry MX red switch: Baco
Seeed Studio XIAO rp2040: Seeed Studio
EC11 rotary encoder: Xindela
0.91" OLED display: John England
